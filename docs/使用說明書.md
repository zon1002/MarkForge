# MarkForge 使用說明書

適用版本：**v1.7.0**　｜　適用系統：Windows 10／11（64 位元）

MarkForge 是 Windows 上的 Markdown 工具組，包含三個部分：

| 元件 | 用途 |
|------|------|
| **MarkForge Editor**（編輯器） | 撰寫 Markdown，左邊編輯、右邊即時預覽；支援圖片／表格／Mermaid 拖入、Word 與 Excel 內容貼上自動轉換 |
| **MarkForge Viewer**（檢視器） | 唯讀檢視 `.md` 檔案，檔案被其他程式修改時自動重新整理 |
| **檔案總管預覽窗格** | 在 Windows 檔案總管選取 `.md` 檔案，右側預覽窗格直接顯示渲染結果，不必開啟任何程式 |

## 1. 安裝與解除安裝

### 1.1 系統需求

| 項目 | 需求 |
|------|------|
| 作業系統 | Windows 10 或 Windows 11，64 位元 |
| .NET 8 Desktop Runtime（x64） | 必要；安裝程式會自動偵測，缺少時可一鍵下載 |
| Microsoft Edge WebView2 Runtime | 預覽功能需要；Windows 11 已內建，安裝程式同樣會自動偵測 |
| 系統管理員權限 | 安裝時需要（會出現 UAC 確認視窗） |

### 1.2 安裝步驟

1. 執行 `MarkForge_Setup_v1.7.0.exe`，在 UAC 視窗按「是」。
2. 選擇安裝資料夾（預設 `C:\Program Files\MarkForge`）。
3. 選擇附加工作：

   | 選項 | 預設 | 說明 |
   |------|------|------|
   | 建立桌面捷徑 | 不勾選 | 在桌面建立 Editor 與 Viewer 的捷徑 |
   | 在檔案總管預覽窗格顯示 Markdown（.md／.markdown） | **勾選** | 註冊檔案總管預覽處理常式，見[第 4 章](#4-檔案總管預覽窗格) |

4. 若偵測到缺少 .NET 8 或 WebView2，會詢問是否自動下載安裝（需要網路）。選「否」可略過，之後再自行到微軟官網安裝。
5. 按「安裝」，完成後可勾選「立即啟動 MarkForge Editor」。

安裝完成後：

- `.md`、`.markdown` 檔案**按兩下**會以 **MarkForge Viewer** 開啟。
- 在檔案上按**右鍵**，選單中會有「**以 MarkForge Editor 開啟**」。
- 「開始」功能表有「MarkForge Markdown 工具組」資料夾，內含 Editor、Viewer 與解除安裝。

### 1.3 更新版本

直接執行新版安裝程式即可，設定與檔案不會遺失。安裝程式會先關閉檔案總管的預覽程序，以免檔案被鎖住。

### 1.4 解除安裝

「設定 → 應用程式 → 已安裝的應用程式」找到「MarkForge Markdown 工具組」→ 解除安裝；或使用「開始」功能表中的「解除安裝」。檔案關聯與檔案總管預覽註冊會一併移除。

## 2. MarkForge Editor

### 2.1 畫面配置

```
┌────────────────────────────────────────────────────────────────────┐
│ 檔案  編輯  插入  檢視  說明                                (選單列) │
│ B 粗體  I 斜體  刪除線 │ 標題▾ │ 引用 清單 編號 工作清單▾ │ …  (工具列) │
├──────────────────────────────┬─────────────────────────────────────┤
│  1 # 標題                     │   標題                               │
│  2                            │   ─────────                          │
│  3 內文 **粗體**              │   內文 粗體                          │
│         （編輯區）            │           （預覽區）                 │
├──────────────────────────────┴─────────────────────────────────────┤
│ C:\docs\note.md                          128 字 / 640 字元  行 3，列 8 │
└────────────────────────────────────────────────────────────────────┘
```

| 區域 | 說明 |
|------|------|
| **選單列** | 所有功能的入口，見 [2.11 選單總覽](#211-選單總覽) |
| **工具列** | 常用格式按鈕，見 [2.3](#23-格式工具列) |
| **編輯區**（左） | Markdown 原始碼，含行號與語法上色；標題會以較大字級顯示 |
| **預覽區**（右） | 即時渲染結果，停止打字約 0.25 秒後更新 |
| **分隔線** | 拖曳可調整左右寬度 |
| **狀態列** | 左：目前檔案完整路徑（未存檔顯示「新檔案（尚未儲存）」）；右：字數／字元數、游標行列位置 |

- 視窗標題顯示檔名，**檔名前有 `*` 代表有尚未儲存的修改**。
- 預設為**深色主題**，可在「檢視 → 切換深色主題」切換成淺色（見 [2.9](#29-檢視設定主題字型寬度窗格)）。
- **編輯區與預覽區會同步捲動**：捲動任一邊，另一邊自動對到相同段落。對齊方式是以標題、程式碼區塊與 Mermaid 圖為錨點，即使幾行 Mermaid 語法渲染成一整頁的圖也能對齊。

### 2.2 檔案操作

| 操作 | 方法 |
|------|------|
| 新增文件 | `Ctrl+N` 或「檔案 → 新增」 |
| 開啟檔案 | `Ctrl+O`、「檔案 → 開啟...」，或把 `.md` 檔案拖進 Editor 視窗 |
| 儲存 | `Ctrl+S`；新文件第一次儲存會詢問檔名 |
| 另存新檔 | `Ctrl+Shift+S` |
| 關閉 | 「檔案 → 結束」或關閉視窗；有未儲存的修改時會詢問是否儲存 |

> **存檔時會自動複製附件**：拖入或貼上的圖片、附件，會在儲存時複製到 `.md` 檔案所在的資料夾，詳見 [2.4](#24-插入圖片與附件)。

**自動接續清單**：在清單項目（`- `、`* `、`1. `、`- [ ] `）或引用（`> `）行尾按 `Enter`，下一行會自動帶出相同的符號；編號清單會自動遞增編號。

### 2.3 格式工具列

選取文字後按按鈕，會套用在選取範圍；沒有選取時插入格式符號並把游標放在中間。再按一次同一個按鈕可取消格式。

| 按鈕 | 產生的 Markdown | 快捷鍵 |
|------|----------------|--------|
| **粗體** | `**文字**` | `Ctrl+B` |
| **斜體** | `*文字*` | `Ctrl+I` |
| **刪除線** | `~~文字~~` | — |
| **標題 ▾** | 下拉選 標題 1～6：`#`～`######`（再選同一層級可取消） | — |
| **引用** | 每行開頭加 `> ` | — |
| **項目清單** | 每行開頭加 `- ` | — |
| **編號清單** | 每行開頭加 `1. `、`2. `… | — |
| **工作清單 ▾** | 按按鈕本體：`- [ ] `（空核取方塊）<br>按箭頭可選：打勾 `- [x]`、打叉 `- [✗]`、三角形 `- [▲]`、驚嘆號 `- [!]` | — |
| **行內程式碼** | `` `程式碼` `` | — |
| **程式碼區塊** | ```` ``` ```` 圍起來的區塊 | — |
| **連結** | `[連結文字](https://)` | `Ctrl+K` |
| **圖片 ▾** | 按按鈕本體：選擇圖片檔案插入；按箭頭可選「插入圖片語法範本」 | — |
| **表格 ▾** | 按按鈕本體：插入 3 欄表格範本；按箭頭可選「從 Excel／CSV／ODS 檔案匯入...」 | — |
| **分隔線** | `---` | — |
| **復原／重做** | — | `Ctrl+Z`／`Ctrl+Y` |

### 2.4 插入圖片與附件

有四種方式，結果相同：

| 方式 | 操作 |
|------|------|
| **拖入** | 從檔案總管把圖片檔拖到編輯區，**放開的位置就是插入點**（拖曳時游標會跟著移動提示位置） |
| **貼上截圖** | 用截圖工具（`Win+Shift+S`）或瀏覽器「複製圖片」後，在編輯區 `Ctrl+V` |
| **貼上已複製的檔案** | 在檔案總管對檔案按 `Ctrl+C`，回到編輯區 `Ctrl+V` |
| **選單** | 工具列「圖片」按鈕，或「插入 → 圖片檔案...」（可多選） |

插入後會產生 `![檔名](檔名.png)`，預覽區**立即顯示圖片——即使文件還沒存檔**。

#### 存檔時的處理

儲存（`Ctrl+S`）時，MarkForge 會把文件中引用到的圖片**複製到 `.md` 所在的資料夾**，Markdown 一律使用相對路徑，因此整個資料夾搬到別處、或用其他 Markdown 工具開啟都能正常顯示。

| 情況 | 處理方式 |
|------|---------|
| 圖片本來就在 `.md` 所在資料夾（或其子資料夾） | 直接引用原檔，不另外複製 |
| 資料夾內已有**同名且內容相同**的檔案 | 直接使用，不重複複製 |
| 資料夾內已有**同名但內容不同**的檔案 | 複製為 `名稱-2.png`、`名稱-3.png`…，並**自動修改文件中的連結** |
| 貼上的截圖 | 命名為 `image-日期-時間-序號.png`，例如 `image-20260924-063213-1.png` |
| 「另存新檔」到其他資料夾 | 原本放在舊資料夾、以相對路徑引用的圖片也會一起複製到新資料夾 |
| 拖入後又把那行刪掉 | 不會被複製（只複製文件中實際引用的檔案） |
| 無法複製（權限不足、來源已刪除） | 文件仍會儲存，並列出未能複製的檔案 |

#### 其他檔案（附件）

拖入 PDF、ZIP 等非圖片、非表格的檔案時，會插入附件連結 `[報告.pdf](報告.pdf)`，存檔時同樣複製到文件資料夾。檔名含空白或括號時會自動寫成 `[報告 v2.pdf](<報告 v2.pdf>)`。也可使用「插入 → 附件檔案...」。

### 2.5 表格：Excel／CSV 貼上與拖入

#### 從 Excel／LibreOffice Calc 複製貼上

1. 在 Excel 選取儲存格範圍，`Ctrl+C`。
2. 在 MarkForge Editor 的編輯區 `Ctrl+V`。
3. 自動產生 Markdown 表格，**第一列成為表頭**：

```markdown
| 品項       | 數量 | 單價 |
| ---------- | ---: | ---: |
| 蘋果       |   10 | 25.5 |
| 香蕉\|芭樂 |  200 |    8 |
```

從其他程式複製、以 Tab 分隔且每行欄數相同的格狀文字，也會自動辨識為表格。

#### 拖入表格檔案

直接把下列檔案拖進編輯區（或「插入 → 表格檔案...」）：

| 格式 | 說明 |
|------|------|
| `.xlsx`、`.xlsm`、`.xls` | Excel 活頁簿（檔案在 Excel 中開著也能讀取） |
| `.ods` | LibreOffice／OpenDocument 試算表 |
| `.csv` | 自動判斷分隔符號（`,`、`;`、Tab）與編碼（UTF-8 或 Big5） |
| `.tsv` | Tab 分隔 |

活頁簿有多個工作表時，每個**非空白**工作表各產生一個表格，表格上方以粗體標示工作表名稱。

#### 表格轉換規則

| 項目 | 規則 |
|------|------|
| 欄寬 | 自動對齊，中文字以兩格寬計算，編輯區內也整齊 |
| 數字欄 | 整欄都是數字時靠右對齊（`---:`） |
| 空白列／欄 | 前後的空白列、右側的空白欄自動去除 |
| 儲存格內的 `\|` | 自動跳脫為 `\|` |
| 儲存格內換行 | 轉為 `<br>` |
| 日期 | 輸出為 `2026-09-01`（含時間則為 `2026-09-01 14:30`） |

### 2.6 Mermaid 圖表

- **拖入** `.mmd` 或 `.mermaid` 檔案（或「插入 → Mermaid 圖表檔案...」），會自動包成程式碼區塊並立即渲染成圖：

  ````markdown
  ```mermaid
  graph TD
    A[開始] --> B{判斷}
    B -->|是| C[結束]
  ```
  ````

- 也可以直接在編輯區手打 ```` ```mermaid ```` 區塊。
- 圖表的縮放與平移操作見 [2.8](#28-預覽區操作)。

### 2.7 從 Word／LibreOffice／Google 文件貼上

從 **Microsoft Word**、**LibreOffice Writer**（ODF／`.odt`）、**Google 文件**複製內容，在編輯區 `Ctrl+V`，會轉成標準 Markdown 寫法：

| 原文件中的格式 | 轉換結果 |
|---------------|---------|
| 標題樣式（標題 1～6／Heading 1～6） | `#`～`######` |
| 「標題」（Title）樣式 | `#` |
| **沒有套用標題樣式、只是把字放大**的段落 | 依字體大小判斷層級（見下表） |
| 粗體、斜體、刪除線 | `**粗體**`、`*斜體*`、`~~刪除線~~` |
| 項目符號清單、編號清單（含多層） | `- 項目`、`1. 項目`，子層級自動縮排 |
| 表格 | Markdown 表格 |
| 超連結 | `[文字](網址)` |
| 文件中的圖片 | 複製保存，存檔時放到 `.md` 資料夾 |
| 引用、程式碼區塊 | `> 引用`、```` ``` ```` 區塊 |

#### 依字體大小判斷標題

MarkForge 會先找出文件的**內文字體大小**（佔最多字數的大小；若整段貼上只有一種大小，視為 12pt），再以每個段落的字體大小與內文的比例決定：

| 段落字體 ÷ 內文字體 | 轉換為 | 例（內文 12pt） |
|--------------------|-------|----------------|
| ≥ 1.75 倍 | `#` 標題 1 | 22pt 以上 |
| ≥ 1.45 倍 | `##` 標題 2 | 約 18pt |
| ≥ 1.25 倍 | `###` 標題 3 | 約 15～16pt |
| ≥ 1.12 倍 | `####` 標題 4 | 約 14pt |
| 其他 | 一般段落 | — |

只有**短段落**（120 字以內、單行）會被判斷為標題，放大字體的長段落維持內文。轉為標題時會去掉多餘的粗體符號。

#### 什麼時候不轉換

- 從 **VS Code** 等程式碼編輯器複製的內容維持原樣貼上。
- 一般純文字直接貼上。
- 需要**保留原始文字、不做任何轉換**時：`Ctrl+Shift+V`（「編輯 → 貼上為純文字」或右鍵選單）。

> 貼上的轉換結果可以用 `Ctrl+Z` 一次復原。

### 2.8 預覽區操作

| 操作 | 說明 |
|------|------|
| 捲動 | 與編輯區同步 |
| **Mermaid 圖表 — 滾輪** | 以游標位置為中心縮放（20%～1200%），不需按 `Ctrl` |
| **Mermaid 圖表 — 左鍵拖曳** | 平移圖表 |
| **Mermaid 圖表 — 按兩下** | 還原成原始大小與位置 |
| 選取文字 `Ctrl+C` | 複製預覽中的文字 |

### 2.9 檢視設定：主題、字型、寬度、窗格

全部在「**檢視**」選單：

| 項目 | 說明 |
|------|------|
| **切換深色主題** | 深色（預設）／淺色切換；選單、工具列、狀態列、標題列、捲軸、編輯區、預覽區一起變換 |
| **顯示編輯器**／**顯示預覽** | 可只留編輯區或只留預覽區；兩者不能同時隱藏 |
| **編輯器字型...** | 編輯區的字型與大小（預設 Consolas 11） |
| **預覽字型...** | 預覽區的字型與大小 |
| **預覽寬度** | 預覽內容的閱讀寬度：860px（預設）／1000px／1200px／1400px／不限制寬度，或「自訂寬度...」輸入 320～4000px；內容置中顯示，此設定也套用到匯出的 HTML |

### 2.10 匯出 HTML 與 PDF

| 功能 | 說明 |
|------|------|
| **檔案 → 匯出為 HTML...** | 產生**單一 HTML 檔案**，樣式、程式碼上色與 Mermaid 全部內嵌，可在任何瀏覽器獨立開啟。圖片維持相對路徑，請把 HTML 存在 `.md` 同一個資料夾 |
| **檔案 → 另存為 PDF...** | 以目前預覽畫面（含主題、字型、寬度）輸出 PDF |

### 2.11 選單總覽

| 選單 | 項目 |
|------|------|
| **檔案** | 新增 `Ctrl+N`、開啟... `Ctrl+O`、儲存 `Ctrl+S`、另存新檔... `Ctrl+Shift+S`、匯出為 HTML...、另存為 PDF...、結束 |
| **編輯** | 復原 `Ctrl+Z`、重做 `Ctrl+Y`、剪下 `Ctrl+X`、複製 `Ctrl+C`、貼上 `Ctrl+V`、貼上為純文字 `Ctrl+Shift+V`、粗體 `Ctrl+B`、斜體 `Ctrl+I`、插入連結 `Ctrl+K` |
| **插入** | 圖片檔案...、表格檔案 (Excel／CSV／ODS)...、Mermaid 圖表檔案...、附件檔案... |

| **說明** | 關於 MarkForge |

## 4. 檔案總管預覽窗格

安裝時勾選「在檔案總管預覽窗格顯示 Markdown」後，不需開啟任何程式就能在檔案總管裡看 `.md` 內容。

### 4.1 使用方式

1. 開啟檔案總管，進入有 `.md` 檔案的資料夾。
2. 開啟預覽窗格：按 `Alt+P`，或工具列右側的「**預覽**」按鈕（Windows 10：「檢視」索引標籤 →「預覽窗格」）。
3. 點選 `.md` 或 `.markdown` 檔案，右側即顯示渲染結果。

### 4.2 顯示內容與行為

| 項目 | 說明 |
|------|------|
| 支援內容 | 標題、清單、表格、程式碼語法上色、Mermaid 圖表、同資料夾（相對路徑）的圖片 |
| 深色／淺色 | 跟隨 Windows「設定 → 個人化 → 色彩 → 選擇您的應用程式模式」 |
| 顯示速度 | 每次選取檔案約 0.5～1 秒顯示 |
| 點擊連結 | 以預設瀏覽器開啟，預覽窗格本身不會跳轉 |
| 大檔案 | 超過 8 MB 的檔案顯示「檔案過大」提示，請改用 MarkForge Viewer 開啟 |

### 4.3 安全性

選取檔案就會顯示預覽，因此預覽窗格做了以下限制：

- **不連線網路**：遠端圖片（`https://…`）、iframe、網路字型一律不載入，避免透過文件追蹤開啟行為。遠端圖片會顯示為破圖。
- 頁面不會被導向其他網址；開發者工具與瀏覽器快捷鍵停用。
- 需要看遠端圖片時，請以 MarkForge Viewer 或 Editor 開啟。

### 4.4 開啟／關閉此功能

- **關閉**：重新執行安裝程式，取消勾選「在檔案總管預覽窗格顯示 Markdown」；或解除安裝。
- **與 PowerToys 的關係**：每種副檔名只能有一個預覽程式。若之前使用 PowerToys 的 Markdown 預覽，安裝本功能後 `.md` 改由 MarkForge 顯示；想換回 PowerToys 時，在 PowerToys 設定中把 Markdown 預覽關閉再開啟即可重新註冊。

## 7. 常見問題與疑難排解

**Q：啟動時出現「找不到 WebView2 Runtime」或「無法初始化即時預覽元件」。**
A：安裝「Microsoft Edge WebView2 Runtime」（<https://developer.microsoft.com/microsoft-edge/webview2/>）後重新啟動。編輯與存檔在沒有預覽的情況下仍可使用。

**Q：程式無法啟動，要求安裝 .NET。**
A：安裝「.NET 8 Desktop Runtime（x64）」：<https://dotnet.microsoft.com/download/dotnet/8.0>。

**Q：Word 貼上後標題沒有變成 `#`。**
A：
- 確認是從 Word 本身複製（不是從 PDF 或網頁）。
- 若原文只是把字放大，放大比例需達內文的 1.12 倍以上，且段落在 120 字以內、只有一行。
- 需要保留原樣時改用 `Ctrl+Shift+V`。

**Q：貼上後不想要轉換。**
A：`Ctrl+Z` 復原，再用 `Ctrl+Shift+V` 貼上為純文字。

**Q：圖片在 Editor 看得到，但用其他程式開啟 `.md` 看不到。**
A：請先存檔（`Ctrl+S`）。拖入／貼上的圖片在存檔時才會複製到 `.md` 所在資料夾。

**Q：存檔後出現「部分檔案未複製」。**
A：訊息中列出的原始檔案可能已被移動或刪除，或目的資料夾沒有寫入權限。把圖片重新拖入一次再存檔。

**Q：CSV 拖入後出現亂碼。**
A：MarkForge 會自動判斷 UTF-8 與 Big5（系統預設編碼）。若是其他編碼（例如 GB2312），請先用 Excel 另存為「CSV UTF-8」。

**Q：檔案總管預覽窗格顯示「沒有預覽可用」。**
A：
1. 確認安裝時有勾選「在檔案總管預覽窗格顯示 Markdown」；未勾選請重新執行安裝程式勾選。
2. 關閉所有檔案總管視窗再重新開啟；仍無效時登出再登入 Windows。
3. 若安裝了 PowerToys，確認 PowerToys 沒有在安裝 MarkForge 之後又重新註冊 Markdown 預覽。

**Q：檔案總管預覽窗格一片空白。**
A：查看 `%LOCALAPPDATA%\MarkForge\PreviewHost\error.log`（在檔案總管網址列貼上此路徑）。常見原因是 WebView2 Runtime 未安裝。

**Q：預覽窗格裡的遠端圖片是破圖。**
A：這是刻意的安全限制（見 [4.3](#43-安全性)）。以 MarkForge Viewer 或 Editor 開啟即可看到。

**Q：要如何回報問題？**
A：請附上 MarkForge 版本（說明 → 關於，或安裝程式檔名）、Windows 版本、操作步驟，以及上述 `error.log`（若有）。
